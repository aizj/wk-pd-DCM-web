## 1. 使用规则

本矩阵不是泛化的研发任务列表，而是每次平台端变更合并前的影响面检查表。任何涉及领域对象、字段、枚举、状态机、接口、事件、权限、配置、数据迁移或页面行为的变更，都必须填写对应IM项，补齐“受影响平台页面、未来外部接入、权限、审计、测试和回滚”后才能合并。本期移动端源码、依赖、构建、页面、交互和本地数据访问均不进入变更范围。

### 1.1 影响等级

| 等级 | 定义 | 合并要求 |
|---|---|---|
| L0 | 仅样式、文案或非业务偏好，不改变状态和接口 | 页面自测、可访问性和截图 |
| L1 | 单页面查询/展示变化，不改变事实模型 | 页面、权限、筛选、空态和回归 |
| L2 | 领域字段、接口、事件、缓存或权限变化 | 契约更新、影响矩阵、前后端联调和回滚证明 |
| L3 | 状态机、直控安全、跨端契约、主数据、数据迁移或生产配置变化 | 产品/安全/架构联合评审、故障注入、平台契约测试和发布门禁；移动端运行时联调另立外部接入事项 |

### 1.2 通用检查项

- [ ] 事实源、主键、版本和幂等键未被隐式改变。
- [ ] API、事件、数据库、缓存、索引、导出和审计影响已登记。
- [ ] P01—P21受影响页面、角色、按钮、筛选、详情和状态展示已登记。
- [ ] 移动端页面、入口、文案、业务状态和本地数据访问保持不变；未来外部接入影响已单列（本期不改移动端代码）。
- [ ] 受影响的WorkItem、通知、交接、配置和数据质量规则已确认。
- [ ] 异常出口、降级、灰度、回滚和历史版本解释已确认。
- [ ] 测试用例、契约样例、trace/截图和复测责任人已指定。

## 3. 并行开发冲突规则

| 冲突 | 解决规则 |
|---|---|
| P04/P05/P06同时修改状态字段 | 以BE-01契约和本矩阵IM-04/05为准；任何页面不得自定义同义状态 |
| BE-03主数据与BE-04指令并行 | 先冻结`vehicleId/enterpriseId`和有效期，指令只引用主键，不等待名称字段 |
| BE-04普通指令与BE-05直控并行 | 两条链共享鉴权/审计底座，但Command与DirectControlAttempt、任务与技术核实分开建模 |
| BE-06告警与BE-07页面并行 | 先提供稳定`Alert/WorkItem`Schema和事件样例，页面不从文案推导状态 |
| 配置发布与业务开发并行 | 规则配置必须有版本/生效时间/回滚；开发环境可用fixture，生产需I-09/I-10门禁 |
| 平台兼容契约与后台开发并行 | 兼容API/事件/夹具先冻结；本期不开发或修改移动端Adapter，接口变化必须更新影响矩阵并通过兼容性评审 |
| 历史静态页与正式页面并行 | 静态页不接生产数据；短期演示若保留，必须标注模拟数据并修正“回执状态/处理中”口径 |
